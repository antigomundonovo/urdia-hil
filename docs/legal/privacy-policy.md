# URDIA-HIL — Privacy Policy

**Last updated:** 2026-10-02
**Contact:** antigomundonovo23@gmail.com

URDIA-HIL ("the App") is a personal, local-first editorial intelligence tool
that helps its single operator research, compose and publish historical
content to their own social media accounts, including their own TikTok
account via the TikTok Content Posting API.

## What we collect

- **Nothing on our servers.** The App runs locally on the operator's own
  computer. There is no central server, no cloud database and no third-party
  analytics. All content, drafts, credentials and logs stay on the
  operator's machine.

## How TikTok data is used

- The App uses the TikTok Content Posting API **only to publish content that
  the operator has explicitly reviewed and approved** in the App's dashboard.
- The App requests the minimum scopes needed for publishing
  (`video.publish`, `video.upload`, `user.info.basic`).
- Basic account information (user id / username) is used only to confirm
  which account the operator connected.
- The App **does not** read, collect, store, share or sell any other TikTok
  user data, does not access followers' data, and does not run any
  background collection.

## Data storage and retention

- Access/refresh tokens are stored locally, only on the operator's machine,
  in a protected configuration file, and are never transmitted to any party
  other than TikTok's official API endpoints.
- The operator can revoke the App's access at any time from their TikTok
  account settings, and can additionally revoke stored credentials through
  the App's own connection revocation function.

## Third parties

- The App communicates only with official TikTok API endpoints (and with
  the social platforms the operator explicitly connects). No data is sold,
  rented or shared with advertisers or data brokers.

## Children

The App is a professional tool for the account owner and is not directed at
children.

## Changes

Any change to this policy will be published at this same URL with an
updated date.
