## 5. Lições/pegadinhas (economizam horas)

- **httpx.Response NÃO é context manager** (diferente de requests) —
  `with httpx.post(...)` quebra em runtime; chamadas diretas.
- Handlers/skills abrem `SessionLocal` própria: testes precisam de
  entidades REAIS commitadas; rotas de teste usam a session da fixture SEM
  commit automático (override de `get_session`) — dar `db.commit()` antes
  de invocar handlers/skills nas mesmas rotas de teste.
- `from X import get_settings` no topo captura o lru_cache ORIGINAL —
  monkeypatch de settings NÃO afeta quem importou assim: passar
  `export_root`/`asset_root` explícitos ao construir `ContentService`.
- ContentPackage tem FKs reais (Opportunity + CanonicalContent) — fixtures
  precisam delas. Job tem FK para workspace/profile.
- Meta/Instagram: token do botão novo JÁ é long-lived (ig_exchange_token
  falha com erro 452 "Session key invalid" — nesse caso, usar
  `ig_refresh_token`); token casa com o secret do SUB-APP do Instagram.
- `.pytest_tmp` do repo pode estar travado por processo externo — usar o
  basetemp do pyproject (já configurado), nunca `git add -A` às cegas com
  temporários no repo (já aconteceu; revertido).
- Incidente 2026-10-02 registrado no CHECKPOINT: OpenCode (ferramenta
  externa do dono) commitou em paralelo e corrompeu uma migração — sempre
  olhar `git status`/`git log` por escritores inesperados; dono autorizou
  encerrar processos opencode se necessário.
