## Motivo
Doc 00 §8 nomeia Hermes (pesquisador/memória), JEV (recomendação) e MiroFish (laboratório) como agentes externos, mas o registro de 16 agentes do Doc 05 não os inclui; o contrato do OpenClaw (orquestrador externo via API) não está especificado em nenhum documento.

## Documento afetado
Documento 00 §8, Documento 05

## Regra anterior
Agentes externos citados sem registro nem contrato.

## Nova regra
Opção A: registrar Hermes/MiroFish como providers (não agents) no Provider Registry, com capabilities próprias; OpenClaw recebe contrato de orquestrador (autenticação máquina-a-máquina + allowlist de endpoints). Opção B: removê-los da V1 até especificação.

## Impacto de produto
Define quem orquestra o sistema externamente e onde a pesquisa auxiliar se encaixa sem virar fonte canônica (Doc 00 §8 preservado).

## Impacto arquitetural
Providers externos entram pelo capability call pipeline existente (governança) — nenhuma via direta ao banco.

## Impacto de segurança
OpenClaw sem raw DB access (Doc 08 já veda); token dedicado + escopo.

## Impacto de dados
Nenhum.

## Impacto de compatibilidade
Nenhum até a integração real.

## Testes necessários
Testes de capability call existentes cobrem providers externos via registro.
